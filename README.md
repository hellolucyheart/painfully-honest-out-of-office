A program that writes one painfully honest out-of-office auto-reply (at most 200 characters) to /output/entry.txt: the sender is away, is not checking email, and the inbox will be just as full — and no more urgent — when they return, yet the reply still thanks the reader for their patience.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
